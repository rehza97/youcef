# Chart Components

A collection of bar and line chart components built with shadcn/ui and Recharts for React 19.

## Bar Chart Components

### 1. ChartBarInteractive

An interactive bar chart with toggleable data series and detailed tooltips.

```tsx
import { ChartBarInteractive } from "@/components/ui/charts";

<ChartBarInteractive />;
```

### 2. ChartBarDefault

A simple bar chart with basic styling and tooltips.

```tsx
import { ChartBarDefault } from "@/components/ui/charts";

<ChartBarDefault />;
```

### 3. ChartBarHorizontal

A horizontal bar chart layout.


## Dependencies

- React 19
- Recharts
- shadcn/ui components (Card, Chart)
- Lucide React (for icons)
- Tailwind CSS

## Features

- ✅ React 19 compatible
- ✅ TypeScript support
- ✅ Responsive design
- ✅ Dark mode support
- ✅ Interactive tooltips
- ✅ Customizable styling
- ✅ Accessibility features
